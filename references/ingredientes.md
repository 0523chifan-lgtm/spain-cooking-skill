# 食材中西對照 + 收據縮寫 + 替代方案

查價腳本要用西班牙文關鍵字。**這份檔案不放價格**——價格一律即時查（見 SKILL.md「查價」），寫死的價格幾個月就過期，反而會誤導。

三個用途：①查價前找對西文關鍵字 ②讀收據時還原縮寫品名 ③貨架上缺貨時找替代。

## 收據縮寫還原

收據品名是全大寫、無重音、常被截斷。常見對照：

| 收據上長這樣 | 實際是 |
|---|---|
| `MUSLO POLLO DESH` | Muslos de pollo deshuesados |
| `PECHUGA POLLO FIL` | Pechuga de pollo en filetes |
| `LOMO FINO` | Lomo de cerdo corte fino（薄切豬里肌） |
| `ACEITE OLIVA 0,4` | Aceite de oliva 0,4º |
| `HARINA FINA DE MAIZ` | 太白粉 |
| `AZUCARITOS BLANCOS` | 糖包（一包約 7–8 g，不是整袋砂糖） |
| `TOMATE TRITURADO` | Tomate triturado（罐裝碎番茄） |
| `PIMENTON DULCE` | Pimentón dulce |
| `GAMBA PELADA CRUDA` | 生的去殼蝦仁 |
| `BOLSA` / `BOLSA RAFIA` | 購物袋，**不是食材，不要入庫** |

看到 `BOLSA`、`DTO`（折扣）、`IVA`、`TOTAL` 這類非商品行要跳過。認不出來的直接問使用者，不要猜。

**注意 Mercadona 收據的價格欄位會往下錯一行**，品名和金額不是同一列對齊的。加總對得上總額才算讀對。

## 亞洲超市才有的食材：替代可行性

**這張表是階段 A1「關鍵食材確認」的依據。** 分清楚「有堪用替代」和「沒有替代」很重要——前者可以硬上，後者硬上就是做出一道四不像。

| 食材 | 西班牙一般超市 | 替代可行性 |
|---|---|---|
| 麻油 | 沒有 | **沒有替代。** 葵花油橄欖油都不帶芝麻香，三杯、蒸魚、涼拌全靠它 |
| 九層塔 | 沒有 | **沒有替代。** albahaca 是西式甜羅勒，主調是茴香甜香；九層塔是辛香帶胡椒味。硬用會變成奇怪的義式中菜 |
| 魚露 | 沒有 | **沒有替代。** 泰式菜的鹹鮮骨幹，用醬油頂替就只是一道中式菜 |
| 豆瓣醬 | 沒有 | **沒有替代。** 麻婆、魚香的底味 |
| 花椒 | 沒有 | **沒有替代。** 麻味沒有任何香料能模擬 |
| 米酒／紹興 | 沒有 | **有堪用替代**：Vino de Jerez（雪莉酒，fino 或 oloroso）最接近，同樣是氧化型釀造、帶堅果鹹香。一般白酒次之，偏酸偏輕 |
| 烏醋 | 沒有 | **有堪用替代**：白醋加一點醬油和糖，酸度對得上但少了陳釀的圓潤 |
| 味噌 | 沒有 | **有堪用替代**：雞湯塊加一點醬油，鹹鮮有了但發酵香沒有 |
| 蠔油 | 沒有 | **有堪用替代**：醬油加糖加一點太白粉水，只是頂替不是取代 |
| 豆腐 | Tofu firme 有，但常缺貨 | 中國超市一定有且更便宜 |

規劃到需要上表任何一樣的菜色時，**階段 A1 就要問使用者有沒有**，不要等到出食譜才發現。

## 選購技巧

- **只買冷櫃和貨架上的包裝品**（若使用者不說當地語言）。肉攤、魚攤、熟食櫃都要開口點餐。
- **Hacendado** 是 Mercadona 自有品牌，**Selección de Dia** 是 Dia 的，通常都最便宜、品質穩定。
- 比價看每公斤單價（`ref_price` / `unit_price`），不要只看單件價格。
- 肉品傍晚常有貼標降價。Dia 的折扣可以直接用 `scripts/dia.py` 查到。
- 亞洲醬料 Mercadona 選擇少，去亞洲超市一次買齊常備。
- **週日多數西班牙超市不開門**，週六先買好；規劃週日的菜要確認食材已經在冰箱裡。
