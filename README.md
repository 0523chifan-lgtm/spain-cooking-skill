# spain-cooking

給在西班牙生活的台灣人用的 Claude skill。解決的是一個很具體的問題：**在 Mercadona 或 Dia 買得到的東西裡，今天煮什麼台菜，而且不要每週都煮一樣的。**

## 它會做什麼

流程刻意分成三個**在時間上分開**的階段，因為實際生活就是這樣：

**A. 討論菜色**（在家、在想）— 先讓你勾冰箱還有什麼，問要不要用剩菜排今天的菜，確認幾菜幾湯幾人份和廚具狀況，給主菜候選讓你挑，再依主菜配副菜和湯，最後產出菜單與帶商品實拍圖的採買清單。**到這裡為止不生食譜。**

**B. 超市現場**（站在貨架前）— 回覆變短、可以傳照片問「這個可以嗎」、找不到就給替代、看到打折可以臨時改菜。改菜會重新檢查蔬菜、爐口、關鍵食材三件事。**這個階段也不生食譜。**

**C. 要開始煮了**（買好了、回到家）— 用實際買到的東西產出完整食譜和上菜時序表。一餐只生一次。

這個切分是這套 skill 最重要的設計。把三件事黏成一條線做完，結果是產出大量會作廢的食譜——實測超過一半的食譜在使用者到超市之後就不算數了，而且他站在走道上根本不會讀。

## 為什麼需要這個

一般 AI 給食譜的幾個問題，這個 skill 針對性處理：

- **推薦會重複**：模型每次都從同樣的先驗出發。解法是把煮菜紀錄當成硬約束，主菜 7 天內不重複、蛋白質和菜系輪替。
- **買不到的食材**：台菜食譜預設你在台灣的超市。解法是查 Mercadona 或 Dia 的即時價格與商品圖，並標注哪些食材只有亞洲超市有、哪些有堪用替代（米酒可以用雪莉酒頂替，九層塔沒有任何替代品）。
- **爐口排不開**：食譜各寫各的，沒人管你只有兩口爐。解法是每道菜標「佔哪一路」，總時間算關鍵路徑，排不出來就換菜。
- **太早給食譜**：你只是在想今天吃什麼，它給你一份三十步的食譜。解法是三階段切分。
- **連續好幾餐沒有蔬菜**：口頭提醒沒用。解法是寫成硬規則，組合裡沒有蔬菜就主動補一道進去。

## 安裝

把整個資料夾放進你的 skills 目錄，或打包成 `.skill` 上傳。

## 設定

第一次使用會跑一輪 onboarding，問五件事並寫進你的 preferences：城市、最常去的超市、廚房設備、採買限制（語言能力／預算／時間上限）、營養傾向。之後除非你主動說要改，都不會再問。

`SKILL.md` 最上面的「個人設定」區塊是所有因人而異的設定，其餘章節都是通用邏輯：

| 設定項 | 說明 |
|---|---|
| 常去的超市 | Mercadona 與 Dia 都能即時查價。選定後只查那一家（兩家都查會讓回覆長一倍） |
| Drive 資料夾 ID | 存偏好、庫存、煮菜紀錄。**留空會跑無記憶模式**，功能正常但每次要重講冰箱狀況 |
| 採買方式限制 | 原作者不說西班牙文，所以預設「只買冷櫃包裝品，不去肉攤櫃檯」。會西文的話拿掉這條會省不少錢 |
| 回覆語言 | 預設繁體中文 |
| 亞洲食材來源 | 你當地的亞洲超市 |

要用記憶功能的話，在 Google Drive 建一個資料夾，裡面放三份 Google Docs：

- `煮飯-preferences`：口味、預算、廚具、忌口、預設份數
- `煮飯-pantry`：冰箱現有食材
- `煮飯-history-YYYY-MM`：當月煮菜紀錄（按月切檔）

## 查價的技術細節

`scripts/mercadona.py` 打的是 Mercadona 官網前端在用的 Algolia 公開搜尋端點；`scripts/dia.py` 打的是 Dia 官網的 search-back 端點。兩者都免登入，回傳品名、價格、每公斤單價和商品實拍圖 URL。

**Dia 另外會回傳折扣資訊**（`discount_percentage`、原價 `strikethrough_price`），Mercadona 的端點沒有。要找特價就查 Dia。

**兩個都不是官方 API。** 金鑰和路徑是從網站前端抓的，隨時可能失效或更換。自用沒問題，但不要拿去做高頻請求或商業用途。壞掉的話 skill 會退回用估計值並明講。

Mercadona 的倉庫代碼（warehouse）預設 4315。多數商品全國定價，各倉價差通常在幾分錢，不值得為此卡住流程。

## 已知限制

- 只支援西班牙的 Mercadona 與 Dia。Eroski、Carrefour、Alcampo 都有 Akamai 等級反爬蟲，換 User-Agent 也是 403，沒有可用的查價路徑。
- 價格是參考價，實體店與線上可能有出入，生鮮秤重區和特價品尤其。憑印象估的價格實測會低估三到五成，所以候選階段只給價位級距。
- Google Drive 連接器不能改文件內容，所以更新採「先改名舊檔、再建新檔」。順序不能顛倒：丟垃圾桶需要使用者授權且可能被拒，改名不需要。
- 亞洲食材（麻油、九層塔、米酒、豆瓣醬等）一律要另外跑亞洲超市，skill 只負責提醒。
- 尚未處理：超出預算的處置規則、煮壞了的失敗診斷。
